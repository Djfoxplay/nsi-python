Exercice 08 Intermédiaire Tri
Tri à bulles
Implémente le tri à bulles : on parcourt la liste et on échange deux éléments adjacents si ils sont dans le mauvais ordre. Répète jusqu'à ce que la liste soit triée. Teste avec L = [64, 34, 25, 12, 22, 11, 90].
Console Python 3
Appuie sur Exécuter
Indice : utilise deux boucles for imbriquées. La boucle intérieure compare chaque paire d'éléments adjacents L[j] et L[j+1] ; si L[j] > L[j+1], échange-les avec L[j], L[j+1] = L[j+1], L[j].
Solution 
def tri_bulles(L):
    n = len(L)
    for i in range(n):
        for j in range(0, n - i - 1):
            if L[j] > L[j + 1]:
                L[j], L[j + 1] = L[j + 1], L[j]
    return L
Exercice 09 Intermédiaire Tri
Tri par sélection
Implémente le tri par sélection : à chaque étape, trouve l'indice du plus petit élément restant et échange-le avec l'élément en position courante. Teste avec L = [29, 10, 14, 37, 14].
Console Python 3
Appuie sur Exécuter
Indice : pour chaque position i, suppose que le minimum est à l'indice i, puis cherche dans le reste de la liste s'il existe un élément plus petit. À la fin, échange L[i] et L[minimum].
Solution 
def tri_selection(L):
    lg = len(L)
    for i in range(lg):
        minimum = i
        for j in range(i + 1, lg):
            if L[j] < L[minimum]:
                minimum = j
        L[i], L[minimum] = L[minimum], L[i]
    return L
Exercice 10 Difficile Tri
Fusion de deux listes triées
Écris une fonction fusion(L1, L2) qui fusionne deux listes déjà triées en une seule liste triée, sans utiliser sorted() ni .sort(). Teste avec L1 = [1, 4, 7, 10] et L2 = [2, 3, 8, 9, 15].
Console Python 3
Appuie sur Exécuter
Indice : utilise deux index i et j. Compare L1[i] et L2[j], ajoute le plus petit au résultat en avançant son index. Puis ajoute les éléments restants avec resultat += L1[i:] et resultat += L2[j:].
Solution 
def fusion(L1, L2):
    resultat = []
    i, j = 0, 0
    while i < len(L1) and j < len(L2):
        if L1[i] <= L2[j]:
            resultat.append(L1[i])
            i += 1
        else:
            resultat.append(L2[j])
            j += 1
    resultat += L1[i:]
    resultat += L2[j:]
    return resultat

Exercice 12 Intermédiaire Recherche
Recherche dichotomique
Implémente la recherche dichotomique dans une liste déjà triée. Retourne l'indice de l'élément cherché, ou -1. Teste en cherchant x = 55 dans L = [2, 10, 23, 40, 55, 71, 88].
Console Python 3
Appuie sur Exécuter
Indice : garde deux bornes debut et fin. Calcule milieu = (debut + fin) // 2. Compare L[milieu] à x et réduis l'intervalle de moitié.
Solution 
def dicho(L, x):
    debut = 0
    fin = len(L) - 1
    while debut <= fin:
        milieu = (debut + fin) // 2
        if L[milieu] == x:
            return milieu
        elif x < L[milieu]:
            fin = milieu - 1
        else:
            debut = milieu + 1
    return -1
Exercice 13 Difficile Recherche
Élément manquant
Une liste contient tous les nombres de 1 à n sauf un. Écris manquant(L, n) qui retourne le nombre manquant, en une seule passe. Teste avec L = [1, 2, 4, 5, 6] et n = 6 (résultat : 3).
Console Python 3
Appuie sur Exécuter
Indice : la somme des nombres de 1 à n vaut n * (n + 1) // 2 (formule de Gauss). Soustrais la somme réelle des éléments de L à cette somme théorique.
Solution 
def manquant(L, n):
    somme_theorique = n * (n + 1) // 2
    somme_reelle = sum(L)
    return somme_theorique - somme_reelle

Exercice 16 Difficile Statistiques
Médiane d'une liste
Écris mediane(L) : trie la liste, puis prends l'élément du milieu si la longueur est impaire, ou la moyenne des deux éléments du milieu si elle est paire. Teste avec [7, 2, 9, 4, 5] (médiane : 5) et [1, 3, 5, 7] (médiane : 4.0).
Console Python 3
Appuie sur Exécuter
Indice : si n est impair, l'indice du milieu est n // 2. Si n est pair, moyenne de L_triee[n//2 - 1] et L_triee[n//2]. Utilise n % 2 == 0.
Solution 
def mediane(L):
    L_triee = sorted(L)
    n = len(L_triee)
    if n % 2 == 0:
        return (L_triee[n//2 - 1] + L_triee[n//2]) / 2
    else:
        return L_triee[n // 2]

Exercice 24 Difficile Dictionnaires
Mot le plus fréquent
Écris mot_frequent(texte) qui retourne le mot le plus fréquent dans une liste de mots. Teste avec ["nsi", "python", "nsi", "code", "nsi", "python"] (résultat : "nsi").
Console Python 3
Appuie sur Exécuter
Indice : compte les occurrences comme avant. Trouve la clé avec la plus grande valeur grâce à max(compteur, key=compteur.get).
Solution 
def mot_frequent(texte):
    compteur = {}
    for mot in texte:
        compteur[mot] = compteur.get(mot, 0) + 1
    return max(compteur, key=compteur.get)

Exercice 29 Difficile Problèmes
Nombres premiers (crible)
Écris premiers(n) qui retourne la liste des nombres premiers entre 2 et n (inclus). Teste avec n = 50.

Solution 
def est_premier(x):
    if x < 2:
        return False
    for d in range(2, int(x**0.5) + 1):
        if x % d == 0:
            return False
    return True

def premiers(n):
    resultat = []
    for x in range(2, n + 1):
        if est_premier(x):
            resultat.append(x)
    return resultat
